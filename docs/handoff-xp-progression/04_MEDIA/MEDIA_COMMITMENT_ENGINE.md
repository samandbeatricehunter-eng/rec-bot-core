# Media Day Commitment XP Engine

## Purpose

A measurable public statement can create Franchise XP when the team defends it on the field. This links Media Day → game → postgame receipt → progression.

## Gradeable vs narrative-only

Gradeable examples:
- hold opponent under 24
- rush for at least 125
- win turnover margin
- named player reaches 100 receiving yards

Narrative-only examples:
- play with more urgency
- be more disciplined
- be more physical

Only gradeable commitments can pay FPP.

## Conditional follow-up

A follow-up can convert broad intent into a metric.

“We need to establish the run.”
→ “What does that look like?”
→ “At least 125 rushing yards.”

Stored as metric/operator/threshold.

## One payout-bearing commitment

Maximum one per franchise per advance. Other answers still affect tone, Tweets, headlines, and storylines.

## Difficulty / payout

- Standard: 600 FPP
- Strong: 1,200
- High-risk: 1,800

Difficulty is context-derived, not user-selected.

## Deterministic grading

Store metric key, operator, threshold, source stat, grading scope, formula version. LLM does not decide success postgame.

Statuses:
- DEFENDED
- MISSED
- VOID

Result can feed reporter follow-up, social receipt, future rivalry/challenge targeting. No extra XP is created merely because media discusses it.

## Anti-exploit

- one payout commitment;
- ungradeable answer cannot pay;
- user cannot choose easiest commitment;
- missing required stat → VOID;
- correction → reversal/re-grade;
- commitment freezes before game.
