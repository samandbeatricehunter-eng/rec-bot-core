# Media Day UI Final

## Non-RTI
- Three contextual questions per Media Day.
- Each question has exactly five fixed answer options.
- Conditional clarifier(s) follow only where needed.
- Answers are deterministic intent records; no semantic NLP required.
- Questions/answers should read as football media, never mention Bronze/Silver/Gold challenge tiers.

## RTI
- Three page blocks: Offensive Immortal, Defensive Immortal, Owner.
- Only incomplete blocks remain visible.
- Completing primary answer + required clarifier persists and removes that page.
- Reload honors completion.
- After all three are complete, show only:
  **All Media Day Statements Have Been Recorded For This Week.**
- Offense/defense blocks remain hyper-focused on the user's custom prospects.
- Owner block covers owner/franchise decisions and may discuss the two prospects together.
