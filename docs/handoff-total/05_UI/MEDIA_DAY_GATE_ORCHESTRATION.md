# Media Day Gate and Interview Orchestration

## Media Day is not a normal page
Media Day exists only as an active post-advance gate.

Users cannot navigate to a permanent editable Media Day page.
The internal gate route requires an unresolved server-issued gate token for:
`user + league + season + stage/week + advance_instance`.

After completion:
- the route expires;
- submitted answers are immutable;
- direct navigation redirects to League Hub;
- a separate read-only Press Conference Archive may display historical questions/answers.

## Non-RTI interview model
The user speaks for the team as a whole.

Respondent identity:
- team logo
- `{team_name}` / city / nickname / "your team"
- never treat the human user as a fictional coach personality unless a future mode explicitly adds one.

When multiple topics are owed, they are phases of one continuous press conference.
Use conversational transitions between:
- prior result
- roster/transaction
- matchup
- rivalry/playoff stakes
- challenge-related theme
- prior public promise

Normal length: 2–4 questions total.
Exceptional event-heavy advance: up to 6.

A conditional tone follow-up counts as one of those questions.

## RTI interview model
Each interview phase has an explicit subject:
- Owner
- Offensive Immortal
- Defensive Immortal

Use the subject's actual stored name in direct address.
Use the corresponding headshot beside replies.

Normal: 1–3 questions per relevant subject.
Maximum: 4 per subject when the data/story warrants it.
Do not interview a subject simply to fill a quota.

Typical order:
Owner → Offensive Player → Defensive Player
but omit irrelevant subjects.

## Reporters
Primary interviewers come from the eight fixed REC media accounts.
Use beat eligibility and storyline continuity, not pure randomness.

Keep one primary reporter through a topic block.
A second reporter may enter with a natural handoff when the beat changes.

## Context panel
Media Day must put useful context in front of the respondent.

Possible cards:
- opponent + records
- playoff seed/odds
- rivalry/GOTW status
- recent H2H
- recent team form
- relevant opponent trend
- relevant player stat line
- transaction/roster delta
- prior quote being referenced
- RTI player's current season line
- Dev opportunity context, when appropriate

Only show context relevant to the current question.

## Question selection
Build a frozen context snapshot before choosing a question.

Use:
- current matchup
- standings
- verified recent results
- imported player/team stats
- roster changes
- transaction history
- challenge assignment theme
- prior Media Day answers/promises
- social receipts
- rivalry/story state
- RTI Persona/Mindset where applicable
- Dev/contract/confidence events
- current progression state when relevant

Never invent missing context.

## Follow-up question
Each primary question carries an optional semantic follow-up.
Ask it only if the first response leaves a useful dimension unresolved:
- confidence
- certainty
- aggression
- accountability
- respect
- expectation

## Free Agency carry-forward
Opening interview fires on REC advance into Free Agency.
Nothing occurs on the REC site between Madden Frenzy bidding rounds.

When REC normally advances out of Free Agency:
- complete the destination-stage advance/import;
- generate the Free Agency Exit interview from the final roster diff and prior opening statement;
- prepend it to the destination-stage interview conversation;
- transition naturally into the destination-stage subject.

## Completion
Answers save immediately.
Users may leave the site/browser and resume exactly where they stopped.
They cannot skip unanswered required questions and continue into that league.

Commissioner emergency operational access may bypass only to fix league/system issues; it does not mark Media Day complete.
